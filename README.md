# Other Knowledge — LLM Systems Background

This branch stores papers removed from the strict edge–cloud collaboration collection.

These papers are useful background on datacenter LLM serving, Prefill/Decode disaggregation, scheduling, heterogeneous GPUs, memory/KV management, speculative decoding, and on-device inference. They do **not** directly execute one inference workflow across an end/edge–cloud boundary, so they are not classified as core edge–cloud collaboration.

## Scope boundary

The strict collection lives on [`edge-cloud-papers`](https://github.com/666loyazzy/-/tree/edge-cloud-papers). A paper belongs there only when both sides of an end/edge–cloud boundary actively participate through model partitioning, collaborative routing, cross-boundary pipeline execution, state exchange, or adaptive offloading.

See [`PAPERS.md`](PAPERS.md) for the 16 moved papers and their exclusion reasons. Original PDFs and existing translations remain under `papers/` for background reading.
