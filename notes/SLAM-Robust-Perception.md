# SLAM robust-perception survey reading guide

## 先回答的问题

经典 SLAM 已经解决了什么，真实机器人长期运行时为什么仍会因为错误数据关联、动态环境、尺度增长和语义缺失而失败？

## 阅读抓手

1. 首轮只读摘要、引言、标准 SLAM 形式化、鲁棒性章节与开放问题。
2. 用“前端感知 -> 数据关联 -> 后端优化 -> 地图表示 -> 决策/主动探索”整理全篇。
3. 区分局部精度和长期鲁棒性：短序列上轨迹误差小，不等于系统能在跨季节、动态物体和感知退化条件下稳定运行。
4. 把文中的挑战映射回 KISS-ICP 与 ORB-SLAM2：它们分别在哪些传感器、场景与数据关联假设下成立？

## 先修知识

概率估计、因子图或图优化的基本概念、传感器模型、数据关联。
