# Background Taxonomy

This branch contains mechanisms adjacent to, but not themselves instances of, strict end/edge–cloud collaborative inference.

- Datacenter LLM serving and scheduling
- Prefill/Decode disaggregation inside a cluster
- Heterogeneous GPU placement
- KV-cache and memory management
- Speculative decoding
- On-device-only inference

The core branch requires an actual cross-boundary collaborative execution path between an end/edge side and a cloud side.
